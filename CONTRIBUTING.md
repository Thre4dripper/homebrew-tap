# Contributing

Thanks for taking the time to help out. This repository only contains Homebrew
packaging — the tools themselves live in their own repositories.

## Where does my issue belong?

| Problem | Where to report |
| --- | --- |
| The tool crashes, misbehaves, or is missing a feature | The tool's own repository |
| `brew install` fails, wrong checksum, dead download URL, missing dependency | [This repository](https://github.com/Thre4dripper/homebrew-tap/issues) |

## How packages get here

Most casks are generated by [GoReleaser](https://goreleaser.com) and pushed to
this tap automatically when a tool cuts a release. Those files start with a
`DO NOT EDIT` header — changing them by hand is pointless because the next
release overwrites the file. Change the tool's `.goreleaser.yaml` instead.

## Adding a package manually

1. Add the file under `Casks/<token>.rb` (prebuilt binaries) or
   `Formula/<name>.rb` (built from source).
2. Use the tool's repository as `homepage`, and stable release assets as `url`.
3. Get checksums with `shasum -a 256 <file>`.
4. Run the checks below, then open a pull request.

## Testing changes locally

```sh
# Point Homebrew at your local checkout
brew tap Thre4dripper/tap
cd "$(brew --repository Thre4dripper/tap)"

# Syntax, style and audit — the same checks CI runs
brew readall --os=all --arch=all --aliases Thre4dripper/tap
brew style Casks/<token>.rb
brew audit --online --except=installed --tap=Thre4dripper/tap

# Real install smoke test
brew install --cask --verbose --debug Thre4dripper/tap/<token>
brew uninstall --cask Thre4dripper/tap/<token>
```

`brew style --fix` autocorrects most formatting complaints. CI only styles
hand-written files: GoReleaser-generated casks are skipped because the next
release would undo any fix.

## Pull request checklist

- [ ] `brew readall`, `brew style` and `brew audit` pass
- [ ] The package installs and the binary runs on at least one platform
- [ ] Version, URLs and `sha256` values match a published release
- [ ] Commit message describes the package and version, e.g.
      `tidefetch 0.2.0` or `tidefetch: fix arm64 checksum`
